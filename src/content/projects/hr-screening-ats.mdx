## The problem

VSky's HR screening tool started as a chain of n8n webhooks — workable at first, but brittle as the logic grew. Scoring behavior was inconsistent between runs, failure modes were hard to trace, and every new role category meant another fragile webhook branch.

## What I built

I led the migration from n8n's webhook chains to a fully custom Google ADK multi-agent system, replacing implicit webhook logic with typed agents and explicit structured handoff protocols between them — so a failure in one stage is traceable instead of silent.

On top of that:

- **Deterministic ATS scoring engine** — a three-layer skill-matching pipeline (normalization, synonym matching, fuzzy token matching) with a weighted config, replacing inconsistent LLM-scored variance with formula-based feature matching
- **Multi-modal resume parsing** — PDF, DOCX, and image resumes handled through a unified pipeline
- **Bidirectional ERP integration** for candidate data sync
- **Role-based access control**, gating which endpoints each agent and user role can reach
- **API consolidation** — collapsed 7 sequential dropdown API calls into a single endpoint, removing redundant round-trips on the add-in's initial load
- A **Vue 3 / Quasar frontend** with an animated donut chart, skill-breakdown chips, and per-role recommendations rendered straight from the deterministic scoring API
- Config-driven weighted matching across roughly **14 role profiles**, so adding a new role is a config change, not new code

## The result

Recruiter screening time on this tool went from **~20 minutes to under 45 seconds per candidate** — the direct result of replacing a variable, re-read-everything manual review with a deterministic score a recruiter can trust and act on immediately.

## Why it matters

This is the project I'd point to for "can you take something fragile and make it dependable." The interesting decision wasn't picking a framework — it was replacing non-deterministic LLM scoring with a deterministic, explainable formula wherever consistency mattered more than flexibility, and reserving the LLM for the parts that genuinely needed judgment.
